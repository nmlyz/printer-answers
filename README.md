printer-answers writes one line to a text file: the office printer's comeback to whoever hammers the Print button fourteen times and then stares at it. The line was picked from 38 candidates by pairwise judging against the brief — a printer that answers the repeated presses with the flat logic of its own queue: the copies are coming, slowly, one by one, and that is not revenge, that is the queue. The printer does not explain the joke twice.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run. The line is 148 characters, a single line, and ends on its reveal. The program holds the line as one constant and checks it against the entry gate (length, single line, no leading or trailing space, exact judged length) before writing it, then reads the file back to confirm the bytes match.
